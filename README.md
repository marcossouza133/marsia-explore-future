# Marsia Expedition Hub

Crie um protótipo front-end chamado MARSIA, uma plataforma futurista de exploração social de Marte.

CONCEITO PRINCIPAL

MARSIA não deve parecer uma loja comum de terrenos.

A ideia é criar a sensação de que o usuário está entrando em uma plataforma de exploração de outro mundo.

O usuário pode explorar Marte, encontrar um território conceitual, adquirir esse território, criar sua identidade de explorador, participar de missões e interagir com uma comunidade.

O território é apenas a porta de entrada para uma experiência maior.

Frase principal:

“Seu primeiro território em outro mundo.”

Importante: os territórios são conceituais/simbólicos e não representam propriedade imobiliária real reconhecida em Marte.

OBJETIVO DESTA PRIMEIRA VERSÃO

Crie somente o MVP visual e interativo.

Não implemente neste momento:

- backend

- banco de dados

- autenticação real

- pagamentos reais

- áudio real

- marketplace completo

- APIs externas

- sistema financeiro

Use dados mockados e interações simuladas.

O objetivo é apresentar um produto visualmente impressionante e demonstrar claramente a ideia da MARSIA.

ESTILO VISUAL

Interface futurista, premium e tecnológica.

Inspiração visual:

- exploração espacial

- interfaces HUD

- mapas de Marte

- tecnologia avançada

- cyberpunk sofisticado

Paleta:

- preto profundo

- cinza espacial

- vermelho/laranja marciano

- branco

- pequenos detalhes luminosos

Use:

- cards translúcidos

- bordas sutis

- glow discreto

- mapas

- indicadores de atividade

- barras de progresso

- microanimações

- transições suaves

Não deixe a interface infantil.

Deve parecer uma startup/produto tecnológico do futuro.

A interface precisa funcionar muito bem em desktop e mobile.

NAVEGAÇÃO PRINCIPAL

Crie uma navegação consistente com:

MARSIA

- Início

- Explorar Marte

- Missões

- Comunidade

- Minha Base

- Meu Passaporte

1. INÍCIO / DASHBOARD

Título:

BEM-VINDO DE VOLTA, EXPLORADOR.

Mostrar:

- nível do explorador

- XP

- território atual

- região

- missão ativa

- atividade da comunidade

Exemplo:

Base Aurora

Elysium Planitia

2.500 m²

Nível 12

7.450 XP

Criar um card de missão:

EXPEDIÇÃO ELYSIUM

“Uma nova área foi identificada próxima ao seu território.”

Botão:

ENTRAR NA EXPEDIÇÃO

Criar também uma pequena seção:

ATIVIDADE EM MARTE

“18 exploradores estão ativos agora.”

2. EXPLORAR MARTE

Criar uma tela de exploração com um grande mapa visual de Marte.

Mostrar regiões como:

- Elysium Planitia

- Olympus Mons

- Valles Marineris

- Utopia

- Gale

- Hellas

O mapa deve parecer interativo.

Criar alguns territórios simulados.

Exemplo:

M-042

2.500 m²

Elysium

Raro

R$99

Botão:

VER TERRITÓRIO

Ao clicar, abrir a tela de detalhes.

3. DETALHES DO TERRITÓRIO

Criar uma página premium para o território.

Mostrar:

M-042

2.500 m²

Elysium Planitia

Raridade: Raro

Status:

DISPONÍVEL

ADQUIRIR TERRITÓRIO

Ao clicar, mostrar um modal de confirmação.

Após confirmar, alterar o estado para adquirido e mostrar:

SEU TERRITÓRIO FOI REGISTRADO

Permitir escolher um nome:

Base Aurora

4. MINHA BASE

Criar uma tela mostrando o território adquirido.

Título:

BASE AURORA

Mostrar:

- região

- área

- nível da base

- XP

- estruturas

Criar uma evolução visual simples:

NÍVEL 1 — TERRITÓRIO DESCOBERTO

NÍVEL 2 — TERRITÓRIO EXPLORADO

Mostrar estruturas como cards:

- Habitat

- Laboratório

- Estufa

Região: Elysium

Área: 2.500 m²

Nível: 12

Título: PIONEER

6. MISSÕES

Criar uma tela de missões com cards.

Exemplo:

Exploração

Dificuldade: 3/5

Objetivo:

Investigar uma região próxima ao Olympus Mons.

Recompensa:

+500 XP

Botão:

ENTRAR NA EXPEDIÇÃO

Criar também uma missão bloqueada para demonstrar progressão.

7. COMUNIDADE

Criar um feed visual com atividades simuladas.

Exemplos:

“18 exploradores estão em Elysium.”

“Uma nova expedição foi criada.”

“Luna completou sua 20ª missão.”

“Elysium Explorers descobriu uma nova área.”

Mostrar também:

23 membros

14 missões

Botão:

VER EQUIPE

Criar uma seção de comunicação chamada:

MARS COMMS

Mostrar salas de áudio simuladas:

- Mission Control — 18 exploradores

- Olympus Expedition — 7 exploradores

- Mars Science Lab — 5 exploradores

Não implementar áudio real. Apenas representar visualmente a experiência.

INTERAÇÕES

A navegação deve funcionar.

Os botões devem levar às respectivas telas.

Use dados mockados.

A aquisição do território deve alterar visualmente o estado da aplicação.

O nome do território deve poder ser alterado no protótipo.

Use modais, notificações/toasts e estados de carregamento quando fizer sentido.

EXPERIÊNCIA PRINCIPAL

A experiência deve deixar clara esta jornada:

ENTRAR → EXPLORAR MARTE → ENCONTRAR TERRITÓRIO → ADQUIRIR → CRIAR BASE → PARTICIPAR DE MISSÕES → CONHECER OUTROS EXPLORADORES

Não transforme o projeto em um simples e-commerce.

A sensação principal deve ser:

“Estou entrando em uma plataforma que poderia existir no futuro.”

RODAPÉ

Adicionar discretamente:

“Os territórios representados nesta plataforma possuem finalidade conceitual e simbólica e não constituem propriedade imobiliária reconhecida sobre Marte.”

PRIORIDADE

Priorize nesta ordem:

1. qualidade visual

2. mapa de Marte

3. navegação

4. detalhes do território

5. aquisição simulada

6. minha base

7. missões

8. comunidade

Se precisar simplificar alguma funcionalidade, simplifique a lógica, não a experiência visual.

Crie um resultado coeso, profissional, futurista e apresentável como protótipo de produto.
